# Remix of Baku Predictor Dashboard Base

Build a Baku GP prediction dashboard for F1 fans who want to explore an XGBoost model’s pre-race predictions.

Use the predictions and metadata in the attached JSON. Show the model’s top pick, driver rankings with horizontal score bars, data-through date, and test performance.

Use a motorsport editorial design: off-white background, charcoal text, red accents, and a large BAKU heading. Make it readable when screen-shared and on mobile and follow this theme that I've attached as an image as well. 

Label percentages “Model score". This first version displays the supplied results snapshot.
